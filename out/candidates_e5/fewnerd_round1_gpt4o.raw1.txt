### CHECK no_duplicate_entities_across_fields
RATIONALE: Correct outputs never duplicate the same entity across multiple fields. This can catch cases where the same entity is misclassified into more than one category.
```python
def check(output, ctx):
    try:
        parsed = parse_json(output)
        if not parsed:
            return True
        all_entities = []
        for field in parsed.values():
            all_entities.extend(field)
        if len(all_entities) != len(set(all_entities)):
            return False
        return True
    except:
        return True
```
