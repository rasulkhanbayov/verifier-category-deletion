### CHECK no_cross_field_overlap
RATIONALE: The same token span cannot belong to multiple fields. Reject outputs where entities overlap across fields.
```python
def check(output, ctx):
    try:
        parsed = parse_json(output)
        if not parsed:
            return True
        text = ctx["text"]
        spans = set()
        for field in parsed.values():
            for entity in field:
                start = text.find(entity)
                end = start + len(entity)
                if any(start < span_end and end > span_start for span_start, span_end in spans):
                    return False
                spans.add((start, end))
        return True
    except:
        return True
```
