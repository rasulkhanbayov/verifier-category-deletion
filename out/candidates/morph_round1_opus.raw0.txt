### CHECK only_allowed_chars
RATIONALE: Canonical morphemes are spelled with letters, plus any punctuation the word itself has, so every correct output passes. This rejects outputs containing digits, spaces or stray symbols.
```python
def check(output, ctx):
    try:
        s = ctx['surface']
        for seg in segments(output):
            for c in seg:
                if not (c.isalpha() or c in s):
                    return False
        return True
    except Exception:
        return True
```

### CHECK no_whitespace_in_segments
RATIONALE: A morpheme never contains whitespace unless the word does. This rejects explanations or prose leaking into segments.
```python
def check(output, ctx):
    try:
        s = ctx['surface']
        if any(c.isspace() for c in s):
            return True
        return not any(any(c.isspace() for c in seg) for seg in segments(output))
    except Exception:
        return True
```

### CHECK similarity_to_surface
RATIONALE: The joined morphemes stay very close to the surface string. This catches outputs that segment a different word.
```python
def check(output, ctx):
    try:
        import difflib
        s = ctx['surface']; j = ''.join(segments(output))
        if len(s) < 4:
            return True
        return difflib.SequenceMatcher(None, s.lower(), j.lower()).ratio() >= 0.4
    except Exception:
        return True
```

### CHECK each_seg_shares_letter
RATIONALE: Every real morpheme overlaps the word's letters. Even inserted canonical vowels like 'y' or 'e' usually appear in the word. This catches junk segments.
```python

    except Exception:
        return True
```

### CHECK first_seg_prefix_match

### CHECK letters_coverage
RATIONALE: Most of the word's letters must reappear in the morphemes, since canonicalisation edits only boundaries. This catches outputs that drop large chunks of the word.
```python
def check(output, ctx):
    try:
        from collections import Counter
        s = Counter(ctx['surface'].lower())
        j = Counter(''.join(segments(output)).lower())
        n = sum(s.values())
        if n < 5:
            return True
        cov = sum(min(s[c], j[c]) for c in s)
        return cov >= 0.5 * n
    except Exception:
        return True
```
