### CHECK answer_bounded_by_question_numbers
RATIONALE: The answer is built by arithmetic on the question's numbers plus small constants (7, 12, 24, 60, 365). It is therefore bounded by the product of those numbers times a generous slack. This catches wildly inflated answers.
```python
def check(output, ctx):
    try:
        import re
        a = final_answer(output)
        if a is None:
            return True
        v = abs(float(a.replace(',', '').replace('$', '').strip()))
        nums = [float(x.replace(',', '')) for x in re.findall(r'\d[\d,]*\.?\d*', ctx['question'])]
        p = 1.0
        for n in nums:
            p *= max(abs(n), 2.0)
            if p > 1e30:
                return True
        return v <= p * 1e7
    except Exception:
        return True
```

### CHECK final_value_parses_clean
RATIONALE: The parsed answer, after stripping '$', ',' and '%', must be a plain float. This catches malformed tokens; anything that does not parse is accepted, so the check stays safe.
```python
def check(output, ctx):
    try:
        import math
        a = final_answer(output)
        if a is None:
            return True
        try:
            v = float(a.replace(',', '').replace('$', '').replace('%', '').strip())
        except Exception:
            return True
        return not math.isnan(v)
    except Exception:
        return True
```
