### CHECK calc_annotation_final_consistent
RATIONALE: A correct final answer that is the result of a `<<expr=val>>` annotation should have an expression that actually evaluates to val, allowing 1% for rounding. This rejects outputs whose final answer comes from a mis-evaluated annotation.
```python
def check(output, ctx):
    import re
    try:
        fa = final_answer(output)
        if fa is None:
            return True
        f = float(fa.replace(',', '').replace('$', ''))
        for m in re.finditer(r'<<([0-9\.\+\-\*/\(\) ]+)=([\-0-9\.,]+)>>', output):
            expr, val = m.group(1), m.group(2).replace(',', '')
            try:
                v = float(val)
            except Exception:
                continue
            if abs(v - f) > 1e-9:
                continue
            try:
                e = eval(expr, {"__builtins__": {}})
            except Exception:
                continue
            if abs(e - v) > max(0.01 * abs(v), 0.01) + 1e-9:
                return False
        return True
    except Exception:
        return True
```

### CHECK last_equation_matches_final_is_correct
RATIONALE: If the last explicit `a op b = c` before the answer line has c equal to the final answer, the arithmetic must hold within rounding. This catches answers taken from a botched final computation.
```python
def check(output, ctx):
    import re
    try:
        fa = final_answer(output)
        if fa is None:
            return True
        f = float(fa.replace(',', '').replace('$', ''))
        body = output.split('####')[0]
        body = body.replace('\\times', '*').replace('×', '*').replace('÷', '/').replace('\\div', '/').replace('$', '').replace(',', '')
        num = r'(\d+(?:\.\d+)?)'
        eqs = list(re.finditer(num + r'\s*([\+\-\*/xX])\s*' + num + r'\s*=\s*' + num + r'(?![\d\.]*\s*[\+\-\*/])', body))
        if not eqs:
            return True
        m = eqs[-1]
        a, op, b, c = float(m.group(1)), m.group(2), float(m.group(3)), float(m.group(4))
        if abs(c - f) > 1e-9:
            return True
        if op in 'xX*':
            r = a * b
        elif op == '+':
            r = a + b
        elif op == '-':
            r = a - b
        else:
            if b == 0:
                return True
            r = a / b
        if abs(r - c) > max(0.01 * abs(c), 0.01) + 1e-9:
            return False
        return True
    except Exception:
        return True
```

### CHECK countable_integer_answer
RATIONALE: When the question asks "how many" of a discrete object and gives no decimals or fractions, the correct count is an integer. This catches outputs that forgot to finish a division or leaked a fractional intermediate.

### CHECK magnitude_bound
RATIONALE: A correct answer cannot exceed the product of all numbers in the question times a generous slack factor (covering implicit constants like days or weeks). This catches runaway multiplication errors.
```python
def check(output, ctx):
    import re, math
    try:
        fa = final_answer(output)
        if fa is None:
            return True
        f = abs(float(fa.replace(',', '').replace('$', '')))
        nums = [float(x.replace(',', '')) for x in re.findall(r'\d[\d,]*(?:\.\d+)?', ctx['question'])]
        nums = [n for n in nums if n > 1]
        logp = sum(math.log10(n) for n in nums)
        if f > 10 ** (logp + 6) and f > 1e7:
            return False
        return True
    except Exception:
        return True
```

### CHECK verbal_arithmetic_final
RATIONALE: Phrases like "a times b is c" whose c is the final answer must be arithmetically valid within rounding. This catches wrong answers stated in prose rather than symbols.
```python
def check(output, ctx):
    import re
    try:
        fa = final_answer(output)

            return True

        pat = r'(\d+(?:\.\d+)?)\s+(times|plus|minus|divided by)\s+(\d+(?:\.\d+)?)\s+(?:is|equals|gives|makes)\s+(\d+(?:\.\d+)?)'
        for m in re.finditer(pat, t):
            a, op, b, c = float(m.group(1)), m.group(2), float(m.group(3)), float(m.group(4))
            if abs(c - f) > 1e-9:
                continue

                r = a * b
            elif op == 'plus':
                r = a + b
            elif op == 'minus':
                r = a - b
            else:
                if b == 0:
                    continue
                r = a / b
            if abs(r - c) > max(0.01 * abs(c), 0.01):
                return False
        return True
    except Exception:
        return True
```

### CHECK latex_frac_final
RATIONALE: A LaTeX `\frac{a}{b} = c` whose c is the final answer must satisfy a/b ≈ c. This catches wrong divisions written in LaTeX.

### CHECK percent_of_bound

### CHECK final_equation_chain_answer
RATIONALE: If the final answer line is preceded by "total = c" with an explicit sum of numbers before it, and c equals the final answer, the sum must be correct within rounding. This catches addition slips in the concluding total.
```python
def check(output, ctx):
    import re
    try:
        fa = final_answer(output)
        if fa is None:
            return True
        f = float(fa.replace(',', '').replace('$', ''))
        body = output.split('####')[0].replace(',', '').replace('$', '')
        ms = list(re.finditer(r'((?:\d+(?:\.\d+)?\s*\+\s*){2,}\d+(?:\.\d+)?)\s*=\s*(\d+(?:\.\d+)?)', body))
        if not ms:
            return True
        m = ms[-1]
        c = float(m.group(2))
        if abs(c - f) > 1e-9:
            return True
        s = sum(float(x) for x in re.findall(r'\d+(?:\.\d+)?', m.group(1)))
        if abs(s - c) > max(0.01 * abs(c), 0.01):
            return False
        return True
    except Exception:
        return True
```
