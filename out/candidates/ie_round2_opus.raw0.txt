### CHECK entity_tokens_in_text
RATIONALE: Gold entities are exact token spans of the text, and the label compares lower-cased values, so every correct string matches a contiguous run of lower-cased tokens. This catches invented, paraphrased or partially fabricated strings.
```python
def check(output, ctx):
    try:
        d = parse_json(output)
        if not isinstance(d, dict):
            return True
        low = ctx['text'].lower().split()
        for k in ["person", "location", "organization", "else"]:
            v = d.get(k, [])
            if not isinstance(v, list):
                continue
            for e in v:
                if not isinstance(e, str):
                    continue
                et = e.strip().lower().split()
                if not et:
                    continue
                n = len(et)
                if not any(low[i:i+n] == et for i in range(len(low)-n+1)):
                    return False
        return True
    except Exception:
        return True
```

### CHECK multiplicity_not_exceeding_text
RATIONALE: Each gold entity corresponds to a distinct mention, so a string cannot be listed more often than it occurs as a token span in the text. This catches outputs that repeat an entity spuriously.
```python
def check(output, ctx):
    try:
        import collections
        d = parse_json(output)
        if not isinstance(d, dict):
            return True
        low = ctx['text'].lower().split()
        cnt = collections.Counter()
        for k in ["person", "location", "organization", "else"]:
            v = d.get(k, [])
            if isinstance(v, list):
                for e in v:
                    if isinstance(e, str) and e.strip():
                        cnt[tuple(e.strip().lower().split())] += 1
        for et, c in cnt.items():
            n = len(et)
            occ = sum(1 for i in range(len(low)-n+1) if tuple(low[i:i+n]) == et)
            if occ and c > occ:
                return False
        return True
    except Exception:
        return True
```

### CHECK no_leading_lowercase_determiner
RATIONALE: A span that begins with a lower-case "the", "a" or "an" in every occurrence in the text is never a gold entity. This catches spans like "the Dodgers".

### CHECK total_entities_bounded_by_tokens
RATIONALE: Gold entities are non-overlapping token spans, so there can be no more of them than there are tokens in the text. This catches hallucinated padding.

### CHECK no_lowercase_common_noun_else
RATIONALE: Only a few well-known lower-case common nouns are covered here, and a span whose every occurrence in the text is one of these lower-case words is never gold. This catches extractions like "war", "meeting" or "record" in the else field.

### CHECK no_month_alone_lowercase_context
RATIONALE: CoNLL does not tag month names. A bare month is rejected only when every occurrence in the text is directly followed by a number, i.e. it is clearly a date. This catches outputs that extract "January" from "January 1".
```python
def check(output, ctx):
    try:
        d = parse_json(output)
        if not isinstance(d, dict):
            return True
        toks = ctx['text'].split()
        months = {"january", "february", "march", "april", "june", "july", "september", "october", "november", "december"}
        for k in ["person", "location", "organization", "else"]:
            v = d.get(k, [])
            if isinstance(v, list):
                for e in v:
                    if isinstance(e, str) and e.strip().lower() in months:
                        idx = [i for i, t in enumerate(toks) if t.lower() == e.strip().lower()]
                        if idx and all(i+1 < len(toks) and toks[i+1][:1].isdigit() for i in idx):
                            return False
        return True
    except Exception:
        return True
```

### CHECK no_trailing_lowercase_common_word
RATIONALE: A span that ends with a lower-case token like "refugees", "embassy" or "boost" in every occurrence in the text is an over-extension of the real entity. This catches spans like "Albanian refugees" and "Greek embassy".
```python
def check(output, ctx):
    try:
        d = parse_json(output)
        if not isinstance(d, dict):
            return True
        toks = ctx['text'].split()
        low = [x.lower() for x in toks]
        tails = {"refugees", "embassy", "boost", "government", "officials", "police", "forces", "troops", "people", "president", "said"}
        for k in ["person", "location", "organization", "else"]:
            v = d.get(k, [])
            if not isinstance(v, list):
                continue
            for e in v:
                if not isinstance(e, str):
                    continue
                et = e.strip().lower().split()
                n = len(et)
                if n < 2 or et[-1] not in tails:
                    continue
                occ = [i for i in range(len(low)-n+1) if low[i:i+n] == et]
                if occ and all(toks[i+n-1] == toks[i+n-1].lower() for i in occ):
                    return False
        return True
    except Exception:
        return True
```

### CHECK no_pure_lowercase_hyphen_phrase
RATIONALE: Multi-token spans whose tokens are all lower-case in the text and all contain no digits are not CoNLL entities. To stay safe against the known "interior ministry" gold, spans containing "ministry" are exempted. This catches extractions like "alien-led profit boost" and "wild card".
```python
def check(output, ctx):
    try:
        d = parse_json(output)
        if not isinstance(d, dict):
            return True
        toks = ctx['text'].split()
        low = [x.lower() for x in toks]
        for k in ["person", "location", "organization", "else"]:
            v = d.get(k, [])
            if not isinstance(v, list):
                continue
            for e in v:
                if not isinstance(e, str):
                    continue
                et = e.strip().lower().split()
                n = len(et)
                if n < 2 or "ministry" in et:
                    continue
                occ = [i for i in range(len(low)-n+1) if low[i:i+n] == et]
                if occ and all(all(toks[i+j] == toks[i+j].lower() and not any(c.isdigit() for c in toks[i+j]) for j in range(n)) for i in occ):
                    return False
        return True
    except Exception:
        return True
```

**Soundness caveats:** The first eight checks and the two structural ones (token count, full sentence) rest only on how gold spans are built. The lists of titles, verbs, common nouns and trailing words come from CoNLL annotation conventions, not hard guarantees. Those checks carry somewhat more risk of rejecting a correct output, so validate them on the full correct set before admitting them. The most likely to fail are:
- **`no_pure_lowercase_hyphen_phrase`**: it already needed an exemption for the "interior ministry" gold.
- **`no_lowercase_common_noun_else`**: it rejects any lower-case word on its list.
- **`no_month_alone_lowercase_context`**: a month name could occasionally be part of a real entity.
