### CHECK entity_is_token_span
RATIONALE: Every gold entity is a contiguous token span of the text, and the label compares lower-cased, stripped strings. So every entity in a correct output, lower-cased and stripped, equals some lower-cased token span. This catches "It's Only...", "(GAMP)", "Dr. Martin Haskell" and "D & E procedure".
```python
def check(output, ctx):
    try:
        d = parse_json(output)
        if not isinstance(d, dict):
            return True
        toks = ctx['text'].lower().split()
        spans = set()
        n = len(toks)
        for i in range(n):
            for j in range(i + 1, min(n, i + 60) + 1):
                spans.add(' '.join(toks[i:j]))
        for k, v in d.items():
            if not isinstance(v, list):
                continue
            for e in v:
                if isinstance(e, str):
                    s = e.strip().lower()
                    if s and ' '.join(s.split()) == s and s not in spans:
                        if len(s.split()) <= 60:
                            return False
        return True
    except Exception:
        return True
```

### CHECK occurrence_bound
RATIONALE: Each gold entity is a distinct token span. So any string can appear across all fields at most as many times as it occurs in the text. This catches "FIFA World Cup 2018" listed as both art and event when it occurs once.
```python
def check(output, ctx):
    try:
        d = parse_json(output)
        if not isinstance(d, dict):
            return True
        toks = ctx['text'].lower().split()
        from collections import Counter
        c = Counter()
        for v in d.values():
            if isinstance(v, list):
                for e in v:
                    if isinstance(e, str) and e.strip():
                        c[e.strip().lower()] += 1
        for s, cnt in c.items():
            st = s.split()
            m = len(st)
            occ = sum(1 for i in range(len(toks) - m + 1) if toks[i:i + m] == st)
            if occ > 0 and cnt > occ:
                return False
        return True
    except Exception:
        return True
```

### CHECK chars_subset_of_text
RATIONALE: Entities are substrings of the text, so every character of a lower-cased entity appears in the lower-cased text. This catches "It's" when the text lacks such a fused form only in combination with the other checks, and also catches invented characters such as curly quotes.

        return True
