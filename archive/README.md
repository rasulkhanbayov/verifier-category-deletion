# Archive

Earlier versions of the project, kept for reference (code and paper source;
large data, logs and caches were removed). The current paper does not depend on
anything here.

* `version1/`: AV-TTS (anatomy-verified test-time scaling), a different MICCAI project.
* `version2/`: SoundVer, "Gate Before You Rank" (EACL draft).
* `version3/`: "Soundness Is a Measurement, Not an Argument" (frozen, not submitted).
  Its SQL label was broken; do not reuse its SQL numbers. Includes the human
  annotation sheets (`version3/data/annotation_sheet_*_labeled.csv`).
