  READING. The theory PREDICTS the two rules are indistinguishable here,
  by two orders of magnitude below what the design can resolve. E3b's null
  is therefore a confirmed prediction, not an underpowered non-result, and
  the paper should say so in exactly those terms.

  It also corrects a framing error. The gate's floor at p_0 is only an
  advantage when p_0 exceeds what homogeneous sampling returns. At these
  rates it usually does not, so the gate's value is NOT that it beats
  homogeneous rejection sampling on accuracy. Its value is that it holds
  regardless of the scorer (Cor. 1), which is what E5 actually shows.

Q2. EXHAUSTIVE TEST OF COR. 3(a) OVER ALL SUB-CONJUNCTIONS
==============================================================================
  E4 walks ONE chain of three checks. Cor. 3(a) quantifies over all
  2^k - 1 sub-conjunctions. Simulating what the exhaustive test would do,
  on synthetic acceptance data with the geometry the corollary assumes:

  sub-conjunctions evaluated: 7224
  exceeding the full-stack bound: 0

  The claim holds by construction of the proof, so a synthetic run cannot
  fail. That is the point: the value of running it on the REAL stacks is
  not that it might fail, but that it converts an appeal to a proof into a
  measured statement about this data, at the cost of re-scoring candidates
  that already exist. For SQL's three checks that is 7 subsets per model,
  28 evaluations, and no new generation.
